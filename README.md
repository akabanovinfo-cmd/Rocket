# Ракета

Аркада на один палец для телефона. Один самодостаточный HTML-файл: canvas,
без сборки, без зависимостей, без сети (кроме шрифтов Google Fonts).

## Играть

Открыть `index.html` в браузере. На телефоне — вести пальцем по экрану,
стрельба автоматическая.

## Локальный сервер (для игры с телефона в той же сети)

```bash
python3 serve.py
```

Слушает порт 8731 на всех интерфейсах и отдаёт правильную кодировку UTF-8.
Адрес для телефона — `http://<ip-компьютера>:8731`.

## Что внутри

- 5 корпусов с разными характеристиками, покупаются за ядра (валюта между забегами)
- 4 вида оружия, 6 модулей прокачки, 12 трофеев-перков
- 4 типа врагов и босс каждый третий уровень
- Вызов дня: сид из даты, одинаковый расклад для всех до полуночи
- Корабль растёт и обрастает деталями по мере прокачки

Прогресс хранится в localStorage браузера.
