# Ракета — правила работы над проектом

Аркада на один палец. Вся игра — **один файл `index.html`** (~93 КБ): canvas,
без сборки, без зависимостей, единственная внешняя загрузка — шрифты Google Fonts.

## Как править код

Файл большой и целиком не переписывается. Правки вносятся **точечным патч-скриптом**
с проверкой каждой замены:

```js
function P(описание, найти, заменить){
  const c = s.split(найти).length - 1;
  if (c !== 1) { failed.push(описание + ' — вхождений: ' + c); return; }
  s = s.replace(найти, заменить);
}
// если хоть один шаблон не совпал — не записывать файл вообще
```

Почему так: замена по неуникальному шаблону молча портит не тот участок.
Уже ловилось — один и тот же цикл `for(i=ebullets.length-1;...)` встречается
дважды, и патч без проверки ушёл бы не туда.

Шаблоны берутся **из фактического файла** (`sed -n`, `grep`), а не по памяти:
лишний пробел в `{id:'hull',  name:` уже стоил двух неудачных прогонов.

## Перед каждой публикацией

```bash
node tests.js
```

Ненулевой код возврата — публиковать нельзя. Прогон занимает около минуты и
покрывает: синтаксис, обычный забег, архив и финал, пять корпусов, семь орудий,
воспроизводимость вызова дня.

Стенд поднимает игру в Node с заглушками DOM и canvas — браузер не нужен.
Всё в одном файле `tests.js`; каждый набор запускается отдельным процессом
(игра живёт на глобальных переменных, два экземпляра в одном процессе конфликтуют).
Отдельный набор: `node tests.js smoke`, `node tests.js finale`, `node tests.js ship:hammer`.

## Как мерить баланс

**Никогда по одному прогону.** Обычный забег берёт случайный сид, разброс
огромный: один и тот же билд давал 6,3 и 14,9 секунды на одном и том же боссе.
Усреднять минимум по 6–8 сидам, показывать среднее и худший случай.

## Особенности окружения

- **Панель предпросмотра рендерит страницы скрытыми** (`visibilityState: hidden`),
  кадры не идут — живой геймплей там проверить нельзя. Для визуальной проверки
  открывать в реальном Chrome через локальный сервер.
- **Неактивная вкладка Chrome душит анимацию** до ~1 кадра в секунду. Для съёмки
  сцены подставлять объекты напрямую, а не ждать их появления.
- **IP машины меняется** при смене сети. Перед выдачей ссылки на локальный сервер
  проверять текущий адрес: `ipconfig getifaddr en0`.
- Локальный сервер: `python3 serve.py` — порт 8731, отдаёт UTF-8 и `no-store`.
  Без правильного заголовка кодировки кириллица превращается в `Ð Ð°ÐºÐµÑ‚Ð°`.

## Публикация

1. `node tests.js` — обязательно
2. Артефакт: публикуется по тому же пути, ссылка сохраняется
3. GitHub Pages: файл заливается через браузер в
   `github.com/akabanovinfo-cmd/Rocket` (токен не используется), Pages
   пересобираются за полминуты
4. Проверить, что развёрнутое совпадает: сравнить `shasum -a 256` локального
   файла и того, что отдаёт `https://akabanovinfo-cmd.github.io/Rocket/`

## Чего не делать

- Не коммитить `_debug_preview.html` и прочие отладочные копии — собирать во
  временный файл и удалять сразу после проверки
- Не вводить чужие токены и пароли ни в какие поля
- Не менять массив вражеских снарядов во время его же перебора — так уже падал
  супер-импульс

## Что в игре сейчас

9 секторов до станции «Заря», босс каждый третий. 5 корпусов за ядра (постоянная
валюта), 7 орудий и 6 модулей за энергию (валюта забега), 14 трофеев-перков
(выбор 1 из 3 после сектора), 7 типов врагов, лазерные ловушки, шкала импульса
за пролёт вплотную к снарядам, архив из 12 обрывков (открываются в том числе за
поражения), 5 витков сложности, вызов дня на общем сиде.
